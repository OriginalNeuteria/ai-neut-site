# ai-neut-site
Official website for Ai-Neut, a journal and a family organizer. Static HTML/CSS, hosted on GitHub Pages.

- Live: https://originalneuteria.github.io/ai-neut-site/ (later www.ai-neut.com)
- App: https://ai-neut.grok.me/
- Pages: index, features, pricing, help, delete-account, privacy, terms, safety, 404
- All links are relative so the site works on both the github.io path and a custom domain.
- `.nojekyll` turns off Jekyll; `.well-known/assetlinks.json` is for the Android app (replace the SHA-256 fingerprint from Play Console > App signing).

Contact: support@ai-neut.com
